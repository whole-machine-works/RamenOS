# P0–P3 Linux editor process delivery

## Outcome and acceptance

Deliver the maintained default-off Linux editor process workflow, including genuine
approval/Read, child-local edit/raster, immutable authenticated publication, and the
common parent Store Save/original-recovery owner. Thirty P0 families and their
finite controls must be independently reviewed before handler authoring. Combined
P1/P2 must execute on Linux. P3 must prove genuine Save, denial, child death,
unrelated-session progress, original-only recovery, and a subsequent successful
Save. Required unchanged consumers and the complete acceptance profile qualify a
fixed candidate. Commits and reviewed PRs deliver that candidate; integration
requires the repository's separate authorized approval. Preparation alone does not
complete this outcome.

Critical path: reviewed private handoff and complete P0 + actual missing-API RED →
concurrent P1 carrier/P2 child → combined runtime acceptance → P3 SaveChains/common
Save integration → independent review and fixed-source qualification → repository
delivery and authorized integration.
